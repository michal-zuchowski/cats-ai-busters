# K65 reference sources

- The bundled documentation in `doc/docs/`, grammar in `compiler/`, and examples in `examples/` come from the [K65 project](https://github.com/michal-zuchowski/k65). They are copied into this project by the K65 IntelliJ plugin.
- The [published K65 documentation by zbyti](https://zbyti.github.io/k65-mkdocs/) ([source repository](https://github.com/zbyti/k65-mkdocs)) is an additional online reference. The bundled `doc/docs/` pages are from the K65 project, not a downloaded copy of the published site.
- [k65-vcs-ai-example by margorski](https://github.com/margorski/k65-vcs-ai-example) is an additional online Atari 2600/VCS example with K65 source, project structure, and AI-oriented notes. Its files are **not bundled**: the upstream repository does not specify a redistribution license. Consult the original source and obtain permission before redistributing its files.

Example project lists may execute scripts and external commands. Do not run them automatically.
